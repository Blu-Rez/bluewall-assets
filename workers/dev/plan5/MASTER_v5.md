## ۲) ریشه‌ی «گیجی» (از F و A) — و درمانش
1. **اسکوت و استقرار یکی‌اند** (تپ اول روی زمین = شروع حمله) → دکمه‌ی صریح ⚔ ATTACK؛ جریان حمله یک ماشین‌حالت با ۷ حالت (A2/A3).
2. **سه ورودی برای حمله**، تنظیمات پنهان، ۶ رنگ تأکیدی، ۱۷۶ رنگ و ۲۴ اندازه‌ی فونت (F) → یک زبان طراحی + یک Assist + یک ⚔ بالا.
3. **پیام‌ها گم می‌شوند** (toast زیر پنل‌ها، نبرد بی‌هپتیک) → مسیر toast یکتا + لایه‌ی بازخورد.
4. **هر انتظاری بی‌درصد نیست** (لودینگ نبرد) → یک حلقه‌ی % برای همه.
5. **قاعده‌ی «دور» در ساخت** (C): قلعه L فقط وقتی همه ≥L−1 → چک‌لیست روشن، نه حدس.
