# ORDER — ترتیب کارها (تصمیم سانت مادر، ۱۴ اکتبر ۲۰۲۶، بعد از نصب p45)
خوانده‌شده با `GIT_FLOW.md` + `MOTHER3_PLAN.md`. وینگلس گفت: «خودت ترتیب همه‌چیز رو بده». این سند همون ترتیبه؛ هر چیزی که عوض بشه اینجا عوض می‌شه.

## اصول (چرا این ترتیب)
1. **اول مدل‌ها (TR2)، بعد کسی که ازشون استفاده می‌کنه (ارتش)، بعد قانون‌ها (جنگ، اقتصاد)، بعد RPG روی همه‌ی این‌ها، آخر QA و انتشار.** هر مرحله پایه‌ی بعدیه.
2. **فقط یک چت کد که فایل‌های مشترک رو عوض می‌کنه (الان TR2).** چت‌های بدون کد (ساخت مدل، ضبط صدا) و چت‌هایی که فقط فایل جدید اضافه می‌کنن (RPG) موازی می‌رن.
3. **بسته‌ها یکی‌یکی** (من ادغام می‌کنم، یه دستور نصب می‌دم). هر پچ که برسه، بعد از گیت و عکس، می‌شه بسته‌ی بعدی (p46, p47, …).
4. **هر چت وقتی باز می‌شه که پیش‌نیازش ادغام شده باشه.** پرامپتش رو من می‌نویسم؛ تو فقط می‌گی «بنویس».

## چی جایگزین چی شد
- **L1 ویرایشگر مپ** = مرحله‌ی S5 چت TR2. چت جدا نمی‌خواد.
- **PPL (مردم)**: راه‌رفتن مردم = S4d تو TR2؛ پادشاه/مالیات = چت ۵.
- **D2 تله‌ها**: ظاهرشون = TR2 (S4)؛ کار واقعیشون = چت ۴.
- **M1–M3 / AR1 / U5 / R1** = چت ۳ (با مدل‌های ارتش جدید، نه مدل‌های رایگان قبلی).
- **A3** (دیوار ۳ ردیف تو نبرد) رفت به چت ۳، چون باید روی دیوار جدید TR2 بشینه.
