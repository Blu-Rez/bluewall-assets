# Blue Wall — بازخورد Wingless بعد از p11 (۱۴۰۵/۰۷/۱۰ ساعت ۱۱:۰۵) — فهرست کار R*/H*

> منبع: پیام خود Wingless با ۶ اسکرین‌شات (لودر، شب+مه، روز، آب، نبرد). این فایل «نیاز» است، نه گزارش. وضعیت اجرا در `claude/p5-progress.md`.
> پیشرفت واقعی بعد از این بازخورد: **~۷۰٪** (اتک باید از نو ساخته شود).

## مهم‌ترین: اتک (R1–R7)
- **R1** مپ دشمن باید **همان مپ اصلی با همان جزئیات** باشد (دیوار، شهر، خندق، کوه، گیاه) با لول و نماد خود دشمن. (الان قلعه‌ی گرد ساده روی زمین تخت.)
- **R2** هویت دشمن: اسم از **لیست اسم‌های بخش گیم ربات** (BlueBot v2 games) — هیچ‌جا کلمه‌ی **BOT / ربات** نوشته نشود. هر کس **پرچم/نماد خاص** دارد (شمشیر/شمشیر خمیده، اژدها، چکش، قلب، …) → یک دسته ایموجی/لوگو برای انتخاب؛ همان بنر روی دیوار. موقع اتک **لول + لوگو + اسم** طرف نمایش داده شود.
- **R3** سرباز/ارتش الان «مزخرف»: مدل درست، ارتش **عمیق و بزرگ**، اسب‌های بالدار **جلوی صف**.
- **R4** **اسپل** باید باشد و قابل‌استفاده؛ از Clash of Clans و Siegefall یاد بگیر.
- **R5** UI و گرافیک نیروها برای استفاده خیلی بد: **لوگوی کمان و شمشیر درست** بگذار. UI ساخت/آموزش سرباز هم اصلاً خوش‌نیامد → از نو.
- **R6** برای اتک **همان انیمیشن ورودی** (همه‌چیز محو، بعد مپ ظاهر می‌شود).
- **R7** بالانس: ارتش و قدرت طوری که **مپ خودم** را در **۳ دقیقه ۳ ستاره** کند.

## بقیه (H1–H5)
- **H1** لودر: متن «Blue Wall» سایه دارد و باگ (دو لایه‌ی ناهم‌تراز). **همان سایه (لایه‌ی پشتی) بماند و نوشته‌ی جلویی (آبی) حذف شود.** تاج هم مثل همان متن پشتی بشود.
- **H2** خزانه‌ی جم‌ها خیلی ساده/بی‌کیفیت؛ حداقل سبز، و قرمز/آبی هم همین؛ وایب خوب نمی‌دهند.
- **H3** پرچم روی دیوار و قلعه را درست کن.
- **H4** مپ اصلی نباید جای خالی داشته باشد؛ بیرون از مپ هر جای خلوت یک خانه/چیزی. ارتش را توی **کمپ‌ها** بگذار و **جلوی مپ یک فضا خالی** بماند (دلیلش را بعداً می‌گوید). اسب بالدار الان دیده نمی‌شود.
- **H5** دیوار و نمای کوه‌ها «خیلی خیلی خیلی» بهتر؛ آب و گیاه اطراف هنوز زشت (گیاه‌ها خیلی)؛ شب: نور/جلوه و بازتاب درست نیست.

## تصمیم‌های تفسیری من (قابل تغییر)
- «نوشته‌ی جلوتر که آبیه»: لایه‌ی جلویی نقره‌ای/سفید با لبه‌ی آبی؛ لایه‌ی پشتی = سایه‌ی تیره‌ی آبی‌-سرمه‌ای با خط دور → همان می‌ماند.
- «بخش گیم ربات»: اسم‌ها از ماژول بازی‌های بات (بازی‌های موجود) خوانده شود؛ اگر لیستی نبود، فهرست اسم فارسی/انگلیسی هماهنگ با همان.
