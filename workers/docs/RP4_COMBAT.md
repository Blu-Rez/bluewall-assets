## Round 1 — what to build
**Step 0 — design doc first (`RP4_design.md`, ≤ 2 pages; the mother reviews it, the owner does not need to):** the numbers table (hero HP, stamina and costs, light-combo damage 3–4 hits with timings, dodge i-frame window ≈ 0.3 s and recharge, hit-stop 50–90 ms, camera shake amount, lock-on rules, enemy HP/damage/telegraph time, skill cooldowns, element multipliers e.g. ×1.5 / ×0.75), the state machines (hero: idle/move/attack n/skill/dodge/hit/knockdown/dead; enemy: idle/chase/windup/attack/recover/stagger/dead), the clip table (which of the 22 clips plays for what; what you retarget from the game's own packs if there is a usable swing — if there is none, say so and use punch/kick/cast for Round 1 and write ONE question to the owner), the input map for touch (attack button big; auto-turn toward the nearest enemy within ≈ 3 m so a thumb never has to aim; skill buttons; dodge exists; lock-on toggle; swap button = later), data tables `SISTERS` (element, role, clips, skills: Elina filled, the other five as data stubs for RP5a–f) and `ELEMENTS` (cycle and tint colours: Elina fire, Elika wind, Melika plants, Mobina earth/stone, Aylin water, Aylar ice).
**Step 1 — the engine (`combat.js`, pure and testable):** a fixed-step (1/60) simulation separate from rendering: hero and enemy state machines, hitboxes as capsules/arcs against capsules, i-frames, stagger/knockback, element multiplier, lock-on target selection (nearest in a view cone ≤ 18 m) and camera assist (the lock-on yaw is a function the host reads; the host keeps its own camera), damage events out (`events[]`: hit, dodge-perfect, kill) for FX/HUD/audio hooks later. No Three.js in the pure part (so Node tests run it): `dev/rp4_test.sh` checks timings, i-frames, combo cancel windows, element multipliers, lock-on switching, deterministic replay with a fixed seed.
**Step 2 — presentation (`combat_fx.js`, `combat_hud.js`):** hit-stop (freeze the hero and victim mixer for N ms, not the whole game), camera shake (a function of events), element slash/trail (ONE pooled ribbon/billboard system, additive, no per-hit allocations, no new lights; a light flash = ONE pooled PointLight at most, off in the quality governor's lower steps), hit sparks, damage digits (Latin digits only), HP/stamina arcs + target HP bar (icons and digits, same glass+turquoise style as the hero buttons), enemy telegraph (a ground ring + flash).
**Step 3 — Elina's kit and a sword from the library:** 4-hit light combo + 2 fire skills (a slash wave and a burst) + the dodge. Render ONE numbered contact sheet of sword candidates from `weapons_swords_*` (6–8 nodes, at hero scale next to the hero's hand) → the owner picks by number (default: the best-looking `sword_med_*`); attach it to the right-hand bone (a node under the bone; no new material beyond the pack's, ≤ +1 program). Weapon swing clips only if Step 0 found a real source; otherwise honest: «the swing uses punch/kick clips + the slash trail; a proper sword clip needs an animator or retargeting — one decision for the owner».
**Step 4 — test arena + placeholder enemies:** `dev/rp4_dev.html` (a flat arena, fog, 3 placeholder enemies cloned from models already in the game — for example `dummy.glb`, `troll`, `cyclops` — clearly marked placeholders, test-only, owner-only; the real enemies are RP6 and come only after the owner picks them from a sheet). Enemy AI = chase, telegraphed attack (windup ≥ 0.5 s so a thumb can react), recover, stagger, death. Max 6 enemies at once. The same `attach(under, hero, opts)` entry will later be called by hero mode in the underworld: your `rpg_hooks_RP4.patch` does exactly that on RP1's test area (`S.under`) so the owner can try it without waiting for RP3.
**Budget:** combat loaded lazily (boot bundle +0 B outside hero mode); ≤ +10 draw calls and ≤ +60 k triangles on screen with 6 enemies; ≤ +4 shader programs (the enemy skinned meshes and the pooled FX only); no per-frame allocations in the hot loop; expose `setQuality(step)` (0 full … 3 lowest: FX density, enemy animation rate, no flash light) so RP1B's quality governor can call it.
