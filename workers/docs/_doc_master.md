# Blue Wall — پلن اصلی (v3) — نوشته‌شده ۱۴۰۵/۰۷/۱۰ (۲ اکتبر ۲۰۲۶) ساعت ۰۵:۰۰ بامداد · به‌روزرسانی ۰۹:۱۰

درخواست‌های Wingless در یک نگاه + ترتیب اجرا + درصد پیشرفت. هر مرحله یک بسته‌ی نصبی جدا (`bluebot_bluewall_pN`)، تجمعی، با همان دستور نصب همیشگی.

## قواعد کار (ثابت)
- فارسی، کوتاه، درصد پیشرفت هر ~۱۰٪. هیچ توکن/سکرتی نه می‌خوام نه می‌نویسم.
- FPS ≥ ۵۵–۶۰ روی گوشی، draw call زیر ~۳۰۰، فقط CC0/CC-BY.
- سرور فقط با بسته عوض می‌شه؛ `py_compile` + تست API قبل از هر بسته؛ migration/داده‌ی قدیمی هیچ‌وقت خراب نشه (state قدیمی Redis خوانده و ارتقا می‌شه).
- سلیقه‌ای‌ها: نمونه‌ی عکس می‌فرستم **ولی کار متوقف نمی‌شه** (او خوابه). نظرش بعداً اعمال می‌شه.

آخرین بسته: **p12** (تجمعی). وضعیت بسته‌ها: `claude/p5-progress.md`.

## مراحل (وزن در پیشرفت کل)

### M0 — بسته‌ی p8: ظاهر + ارتش پایه (۱۵٪)
1. لودینگ: همون فونت؛ «شیشه‌ی پشتش» حذف؛ رنگ/گرادیان شکیل‌تر (نقره‌ای-یخی آبی، لبه‌ی ظریف). **انجام‌شد**
2. آب/خندق: خندق داخلی حذف، فقط خندق بیرونی؛ آبی‌تر و طبیعی‌تر، لبه‌ی سنگی. **انجام‌شد** (آبشار ساخته شد (p10))
3. رنگ ساختمان‌ها: پالت متنوع (آبی کمرنگ/آبی/آبی پررنگ/مشکی/چوبی/جگری/سبز). **انجام‌شد** برای خانه‌های شهر.
4. کیفیت روز: درخت‌ها، آب، کوه، زمین؛ نما با جزئیات بیشتر. **بخشی**
5. ارتش پایه، سواره‌نظام K3، پرچم‌ها، کوه‌ها. **انجام‌شد**

### M1 — جم‌ها، خزانه‌ها، معدن‌ها (۱۰٪) — **انجام‌شد**
- جم‌های سه‌بعدی، ۳ خزانه‌ی پرشونده به‌اندازه‌ی موجودی، معدن‌های بزرگ‌تر.

### M2 — سیستم لول ۱..۲۰ (۱۲٪) — **انجام‌شد**
- ۱ چوب · ۴ سنگ · ۸ آهن · ۱۲ طلا · ۱۶ الماس · ۲۰ کریستال آبی؛ دیوار، برج، ساختمان، لباس سرباز؛ لول بالاتر بزرگ‌تر.

### M3 — ارتقا، سازنده‌ها، اقتصاد (۱۵٪) — **انجام‌شد**
- ارتقا ۱ ساعت تا ۷ روز، سازنده ۱/۲/۳، رزرو، مکس‌کردن ≈ ۳۴۳ روز (شبیه‌ساز). منوی پایین-راست (Owned/Reserve/Buy/New). جزئیات اعداد: `claude/bluewall-progress-military-design.md`.

### M4 — نیروها، آموزش، دکمه‌ی حمله (۱۳٪) — **انجام‌شد**
- ۱۰ نوع نیرو، ظرفیت طبق پادگان/اصطبل/آشیانه/کارگاه/میدان، صف آموزش، دکمه‌ی ATTACK با درصد آماده، ساختمان‌های نظامی (اصطبل کنار مرتع، کارگاه محاصره، آشیانه…).

### M5 — حمله (۲۸٪) — سبک Siegefall / Clash of Clans — **انجام‌شد (مالک-فقط)**
- scout (بازیکن آفلاین/ربات ۱۰٪ ضعیف‌تر تا ۵۰٪ قوی‌تر)، صحنه‌ی نبرد جدا با ارتش مقابل قلعه، ارسال هر دسته به هر نقطه، جنگ واقعی، تخریب، صدا، کارت نتیجه، HOME و NEXT. سرور: `/api/scout`، `/api/battle/end` با اعتبارسنجی.
- **مونده**: شبیه‌سازی سمت سرور برای ضدتقلب قبل از عمومی‌شدن؛ تنظیم بالانس بعد از بازخورد مالک؛ قدرت‌های ویژه‌ی قهرمان.

### M6 — پرداخت نهایی (۷٪)
- پرفورمنس (شب/bloom)، لندسکیپ، تست کامل، مستندات.

## تصمیم‌هایی که خودم گرفتم (چون او خوابه؛ هر کدوم قابل تغییر)
- «شیشه‌ی پشت فونت» = لایه‌ی glow/ضخامت پشت تایتل؛ حذف و فقط گرادیان تمیز.
- «مال داخل رو پاک کن» = خندق دور Blue Wall (داخلی) حذف، خندق دور دیوار شهر (بیرونی) می‌مونه.
- «اول هعژ باز میشه یا رزرو یا خرید یا جدید» = تب‌های منوی پایین-راست: Owned / Reserve / Buy / New.
- «لشگر بستگی به لول دارد» = ظرفیت و نوع نیرو با لول پادگان/اصطبل/آشیانه.
- حمله فعلاً فقط برای مالک (سرور شبیه‌ساز نداره)؛ با `BLUEWALL_ATTACK=public` باز می‌شه.
- اسب بالدار = سفید+خاکستری با بال، جایگزین گریفون.
