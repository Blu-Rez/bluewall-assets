## What changed
1. **Night animals:** moo / neigh / neigh2 / bark / rooster only when `day = 1 − P.night > ANIMAL_DAY (0.55)` (dusk and dawn count as night, ±0.05 margin over the 0.5 asked for). Rooster at game hour 6 only if that holds. The animal timer keeps running at night, it is just silent. Owl at night (> 0.6) unchanged.
2. **The ding:** the spectrum (OfflineAudioContext in headless Chromium for every synthesized sound; decoded mp3 × loudest in-game volume `ONESHOT_MAX` for files) found pure lines above 1.8 kHz in `coins()` (1981 Hz @ −18.4 dBFS: four triangle notes 1.3–2.6 kHz), `sfx_bell` (3359 Hz @ −23.8, 12 s, six strokes), `chime` (2239 Hz @ −15.6), `freeze` (3036 @ −21.0), `clang` (3424 @ −21.3), `sword` (2239 @ −18.4); `sfx_anvil` had a sustained 2562 Hz ring; `fanfare_win` 2089 @ −24.1 (borderline). Now none is above −24 dBFS (worst: clang 2024 Hz @ −33.1, anvil 3876 @ −31.0, bell 3359 @ −53.0). `coins()` is now three soft sine notes (523/660/784 or 587/740/880 Hz, low-pass 1.5 kHz, ≈ 7 dB quieter, ≥ 0.18 s apart). Bell: first 3 strokes only, 24 dB/oct low-pass 1.5 kHz, quieter (≤ 0.55, was ≤ 0.65; measured ≈ 4 dB lower RMS) and once per game day (noon; was every 3 game hours). Anvil: notched / low-passed, ≈ 6 dB quieter by RMS (measured). `bsfx.js`: horn/fanfare/cheer refactored into `hornTo/fanfareTo/cheerTo` + a `render()` test hook; sword / clang / chime / freeze partials softened. The sounds are numbered 10–17 in the sheet (revert = say the number).
3. **Crossfade:** one entry point `playTrack(name)`: the old track fades (equal-ratio ramp, −50 dB floor then exact 0, starting from its current level) over 2.5 s on the audio clock; only then the next is loaded (`src`), and it fades in over 2 s from the `playing` event. One `<audio>` element → per-track `GainNode` → music bus. A track also fades out by itself over its last 2.5 s. Mode changes (day / night / storm) have a 40 s dwell and a night hysteresis (in > 0.6, out < 0.45); rapid flips collapse into ONE change (the last wish). Hidden tab = suspended context = the wait simply pauses (no restart storm). Error / missing file → skip to the next (max 5).
4. **New tracks** (synthesized in `dev/au1_music.py`: harp-pluck, detuned-saw pad, flute, cello-ish line, soft bell, noise-built stereo reverb; nothing sampled, nothing copyrighted): `mus_calm_dawn` 384 848 B 48 s, `mus_calm_meadow` 392 624 B 49 s, `mus_calm_river` 354 896 B 50.6 s, `mus_calm_hearth` 380 240 B 47.4 s, `mus_calm_moon` 353 888 B 50.5 s. Each ≤ 400 KB; new total 1 866 496 B (≤ 2 MB). −19.5 … −24.4 LUFS (old ones −10 … −17, so `g` trims: day1 ×0.5, epic ×0.75 — my judgement, easy to change in `TRACKS`). `TRACKS` also holds the hour windows. The 4 old tracks are byte-identical to the kit.

## Proven (by `dev/au1_test.sh`)
- 48 game hours on a virtual clock (real `audio.js` + `tod.js`, mocked AudioContext / `<audio>` / timers), 3 seeds: 0 animal sounds while dark, ≈ 210 by day, owls only at night, bell exactly 2, rooster exactly 2; constant-light sweep: silent at night ≥ 0.45 … 1.0, 280+ calls at 0.44 … 0.
- Gain sampling every 50 ms: every track switch happens at level ≤ 0.004 (−48 dB); never two audible tracks (one element + silent switch); biggest step ≤ 0.14 per 50 ms; our level bookkeeping equals the AudioParam automation (< 0.02); fade-out 2.55 s, fade-in 2.0 s to 95 %; end-of-track fade; hidden-tab run (10 virtual minutes) = 0 source changes, 1 after return; flicker tests; hour windows and no repeat within the last 2.
- Mutation check: breaking each rule (animals always, fade 0.4 s, no fade, no dwell, no hour windows) makes the test FAIL.
- Spectrum: 44 one-shots (29 synthesized × 6 seeds, 15 mp3), none with a pure line > 1.8 kHz over −24 dBFS (a «pure» line = narrow, ≥ 18 dB over its floor, holding its pitch ≥ 0.12 s; voice harmonics that glide are not dings but are listed as «any-frame» info: neigh2 −18.4, rooster −18.3 — animal voices, daytime only).
- Assets: sizes, LUFS −26..−17, peak ≤ −1 dBFS, first / last 20 ms silent, stereo mp3, TRACKS ↔ files, ONESHOT_MAX covers every sfx.
