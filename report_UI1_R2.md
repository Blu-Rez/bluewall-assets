## What it is
Round 1 gave the building sheet and the Kingdom page the owner-approved look **C «Parchment & metal»** (dark leather, brass hairlines, parchment cards, embossed brass primary button). Round 2 puts the same look on the rest of the player UI, so nothing in the game is still the old blue glass:
1. **HUD** — castle-level badge (brass hex + gear, own SVG), name / cup chip, resource bars and gem chips as leather+brass plates, Assist button, corner Kingdom button. The endless `bwFull` pulse (resource bar full) and the Kingdom button's `bwuGleam` are removed.
2. **Assist hub** (`assist.js`, source untouched) — leather tiles, brass rims, the hot tile keeps its brass rim; its six endless animations (`bwhBr / bwhSp / bwhPu / bwhEd / bwhSw / bwhGl`) are switched off by one CSS override in my file (`animation:none`).
3. **Army screen** (`armyui.js`) — troop / spell cards as parchment cards, rarity rings kept (semantic), housing meter, queue pills, unit-info and spell-info sheets, emblem picker, footer buttons. `bwaGleam` removed. Info «i» button moved to the card's top-right so it no longer sits on the cost row.
4. **Shop** (`shopui.js`) — tabs, boost / defense / gem cards, buy buttons, notes (dark-on-parchment contrast fixed), «How it works» block.
5. **Rank · Clan · Friends · Log** (`rankui.js`, `socialui.js`) — header, league badge, progress bar, leaderboard rows (top-3 medals gold / silver / bronze instead of cyan / white / steel), league list, invite page, clan create / join list / my clan, friends list, battle log. League colours stay (semantic).
6. **Settings** — tabs, sliders, toggles, about page.
7. **Toasts + dialogs** everywhere (z-order unchanged).

Rules kept from round 1: no `backdrop-filter`, no endless animation / `@keyframes` / transition in my file (the file only contains `animation:none` overrides), every target ≥ 44 px (incl. `::before` hit areas), system fonts only (`Cinzel, 'Libre Baskerville', Vazirmatn, Georgia, serif` as a stack; **no web font is loaded**), short English texts, +0 shader programs, portrait 390 and landscape 844.

Vetoable: delete the one override line and they come back. `assist.js` also hides the old corner buttons, so `bwuGleam` / the Kingdom corner button was dead code in the real game (I forced it visible in one test frame to see the change).
- **Landscape Kingdom list** is still only ≈ 140 px tall (builder row + tabs + categories take the rest); a real fix needs a markup / layout restructure of `upgradeui.js`, which is outside «visual layer only» — left, listed.
- **Portrait Rank / Clan header** wraps the sub-line to two lines when the number is long («1,480 cups · rank / #6»): no clipping, no overlap, but not one line. A one-line fix needs shorter text in `rankui.js` (not touched).
