# Blue Wall — concept art (branch `art`)

`cast/<key>.png` = character design sheets (photoreal, 1024x1536): front / side / back + detail panels.
`cast/index.json` = key, Persian name, file. Made with the OpenAI image API on blue18 (/root/bw_art).

Get it (small, no 4 GB main): `git clone --depth 1 --branch art https://github.com/Blu-Rez/bluewall-assets.git`
