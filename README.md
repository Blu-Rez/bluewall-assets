# lib-tripo — the Tripo model library of Blue Wall (226 GLB)
Orphan branch: clone it alone and fast:  `git clone --depth 1 --branch lib-tripo https://github.com/Blu-Rez/bluewall-assets.git tripo_lib`
Layout: `lib/tripo/<category>/<key>/{<key>.glb, credit.json}` · `MANIFEST.json` (226 rows) · `LIB_INDEX.md` (tris / KB / note per key).
All models: made on the owner's own paid Tripo account ("owned by the game"). 1 material, WebP texture ≤ 1K, meshopt + quantised (GLTFLoader needs MeshoptDecoder), base on y = 0, longest side ≈ 1, facing +Z / real scale / pivot NOT fixed yet (TR2 stage S1).
Written by TR1 (14 Oct 2026), pushed here by the mother chat. Ask the mother before changing a model.

`tools/` = TR1's tools (inv.mjs = GLB stats, slim_uv.mjs = UV-aware slimmer, sheet.py + tr1_sheet.html = picture sheets, TR1_list.md = the 112 game models, TR1_progress.md = TR1 log).
